# プライバシーポリシー

「まいにち台湾華語」(以下「本アプリ」) の運営者 (まいにち台湾華語 開発者。以下「運営者」) は、本アプリの利用者の情報を、このプライバシーポリシーに従って取り扱います。

制定日: （公開日を入れる）

## 1. 取得する情報

本アプリは、次の情報を取得します。

1. **アカウントの情報**
   - 本アプリは、初めて起動したときに匿名のアカウントを自動で作ります。氏名やメールアドレスの登録は必要ありません。
   - Google アカウントでログインした場合は、Google から受け取るメールアドレス、名前、プロフィール写真。
2. **プロフィールと設定**
   - ニックネームとアイコンの画像 (利用者が設定したもの。Google アカウントでログインし、まだ設定していない場合は、Google の名前と写真を初期値として使います)。
   - 表示する言語、ルビの表示、1 日の学習時間、学ぶ技能、学習リマインダーの時刻、音声の声などの設定。
3. **学習の記録**
   - 問題への解答の記録、復習の予定、獲得した XP と連続学習日数、お気に入りの問題、レベル判定テストの結果。
4. **問題の報告**
   - 利用者が問題の誤りを報告したときの、報告の理由と自由記述 (500 字まで)。
5. **音声**
   - スピーキングの問題でマイクに向かって話した音声。音声は端末の音声認識機能で文字にし、その結果だけを採点に使います。運営者は音声そのものを受け取りません (3 の「端末の音声認識」も参照してください)。

本アプリは、広告の配信や、利用状況を分析する外部のサービス (アクセス解析など) を使っていません。また、位置情報、連絡先、端末の識別子 (広告 ID など) は取得しません。

## 2. 利用目的

取得した情報は、次の目的に使います。

- 学習の記録を保存し、復習の予定や、利用者に合った問題を出すため。
- 複数の端末や、Google アカウントでのログインで、学習の記録を引き継ぐため。
- レベル判定テストの結果から、苦手な分野の分析と学習の計画を作るため。
- 報告をもとに教材の誤りを直し、本アプリを改善するため。
- 問い合わせに対応するため。

## 3. 外部のサービスへの提供

本アプリは、次の外部のサービスを使っており、それぞれに必要な情報を送ります。これらの事業者は米国にあります。各事業者の個人情報の取り扱いは、それぞれのプライバシーポリシーをご覧ください。

| サービス | 事業者 | 送る情報 | 目的 |
|---|---|---|---|
| Supabase | Supabase, Inc. (米国) | 1 の 1〜4 の情報 | データの保存 (サーバーの所在地: 日本 (東京)) |
| Google ログイン | Google LLC (米国) | Google アカウントでのログインの手続き | ログイン (利用者が選んだ場合のみ) |
| Claude API | Anthropic, PBC (米国) | レベル判定テストの級・技能ごとの得点と、間違えた問題の内容 | 苦手の分析と学習の計画の作成 |
| GitHub | GitHub, Inc. (米国) | 報告の理由・自由記述と、報告された問題の情報 | 運営者が報告を管理するため |
| Resend | Resend, Inc. (米国) | 報告の理由・自由記述と、報告された問題の情報 | 運営者への報告の通知 |

- Claude API、GitHub、Resend には、利用者の名前、メールアドレス、アカウントの ID は送りません。
- 運営者は、法令に基づく場合を除き、利用者の同意なく、上記以外の第三者に情報を提供しません。

**端末の音声認識**: スピーキングの問題の音声は、端末 (Android など) の音声認識機能で処理します。端末やその設定によっては、音声が端末のメーカーや OS の提供者 (Google など) のサーバーに送られて処理されることがあります。その取り扱いは、各提供者のプライバシーポリシーに従います。

**教材の音声**: 教材の音声は、運営者があらかじめ作ったものです。利用者の情報を使って作ることはありません。

## 4. 端末に保存する情報

本アプリは、オフラインでも学習できるように、教材、教材の音声、設定、学習の記録の一部を端末に保存します。本アプリを削除すると、端末に保存した情報も削除されます。

## 5. 保存する期間と削除

- 情報は、アカウントがある間保存します。
- **学習データのリセット**: 本アプリの「アカウント」画面から、学習の記録 (解答の記録、復習の予定、お気に入り、レベル判定テストの結果) を削除できます。
- **アカウントの削除**: 本アプリの「アカウント」画面から、アカウントを削除できます。削除すると、運営者のサーバーにある 1 の 1〜4 の情報はすべて削除されます。
- ただし、すでに運営者に届いた問題の報告の内容 (GitHub の記録と通知のメール) は、教材の改善のために残ります。これには利用者の名前やアカウントの ID は含まれません。

## 6. 安全管理

運営者は、通信の暗号化や、利用者本人だけが自分のデータを読み書きできるアクセス制御などにより、情報の漏えい、紛失、改ざんを防ぐよう努めます。

## 7. 子どもの利用

本アプリは、13 歳未満の子どもを主な対象としていません。13 歳未満の方が本アプリを使う場合は、保護者の同意を得たうえで使ってください。

## 8. 利用者の権利

利用者は、本アプリの画面から、自分の情報の確認、変更、削除ができます。そのほか、開示、訂正、利用の停止などの求めは、10 の問い合わせ先までご連絡ください。

## 9. このポリシーの変更

運営者は、必要に応じてこのポリシーを変更することがあります。重要な変更をするときは、本アプリまたはこのページでお知らせします。
